# 🩺 Diabetes Prediction System

## 📌 Overview
A Machine Learning web application that predicts whether a patient is likely to have diabetes using the Pima Indians Diabetes Dataset.

## 🚀 Features
- Predicts diabetes using Machine Learning
- Confidence score for each prediction
- User-friendly Streamlit interface
- Fast and interactive web application

## 🛠 Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## 🤖 Machine Learning Models Tested
- Logistic Regression
- Decision Tree
- Random Forest ⭐ (Best Model)
- K-Nearest Neighbors (KNN)

## 📊 Best Model
Random Forest

## 📂 Project Files

- app.py
- diabetes_model.pkl
- diabetes.csv
- Medical_Diabetes_Prediction.ipynb
- requirements.txt
- README.md

## ▶️ Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```
